# Ssymmank lamp

Geometry and 3D-printable parts for the Günter Ssymmank Philharmonie lamp.

The lamp is a **spherical tessellation of regular pentagons, squares and
triangles** — i.e. the **rhombicosidodecahedron** (an Archimedean solid):

| | count |
|---|---|
| pentagons | 12 |
| squares | 30 |
| triangles | 20 |
| vertices | 60 |
| edges | 120 |
| faces | 62 |

Vertex configuration is `3.4.5.4` (triangle, square, pentagon, square meet at
every vertex).

Source / reference exhibition:
https://blog.sbb.berlin/darunter-sieht-man-gut-aus-ausstellung-zu-den-leuchten-guenter-ssymmanks-eroeffnet/

## Layout

```
src/        Python geometry tools
models/     OpenSCAD models (the printable parts + the frame)
images/     reference renders (committed)
renders/    transient previews / STL exports (git-ignored)
```

### `src/` — geometry tools
| file | what |
|---|---|
| `geometry.py` | single source of truth — vertices, edges, faces of the solid |
| `mockup.py` | renders `images/mockup_faces.png` and `images/mockup_frame.png` |
| `make_scad.py` | emits `models/lamp_frame.scad` (frame as one monolithic piece) with coordinates baked in |
| `make_star.py` | emits the **printable decomposition** — `star.scad`, `connector.scad`, `stars_assembly.scad`, `mate_test.scad` |

### `models/` — OpenSCAD
| file | what |
|---|---|
| `mushroom.scad` | detailed mushroom element — curved (spherical) pentagon cap, smooth funnel→cap blend, clipped back ribs. Accurate but heavy to render. |
| `mushroom_simple.scad` | **simplified, fast-loading** mushroom — curved (spherical) pentagon cap + cheap fins. Previews in ~0.5 s. Parametric on `STEM_LEN`; `CURVE_CAP=false` reverts to a flat cap. |
| `mushroom_small.scad` · `mushroom_medium.scad` · `mushroom_large.scad` · `mushroom_xl.scad` | the simplified mushroom at four stem lengths (70 / 84 / 100.8 / 120.96 mm, +20 % each). Each just `include`s the core and overrides `STEM_LEN`, so the stem base is identical across all of them. |
| `lamp_frame.scad` | the frame, generated by `make_scad.py`: **72** cylindrical sockets (60 polyhedron vertices + 12 pentagon centres; each points outward and accepts one mushroom stem) + **180** flat edge bars (120 edges + 60 pentagon spokes), each 2 mm thick × 10 mm tall, standing radially |
| `assembly.scad` | the full lamp (generated by `make_assembly.py`): the frame with all 72 mushrooms. Per pentagon: XL in the centre socket, s/m/l/m/l clockwise from the top corner, each oriented so its top points radially outward from the pentagon centre. Mushrooms are scaled by `MUSH_SCALE` (≈0.52) so that **no two ever touch** (verified with a nesting-aware surface model, ≥2 mm clearance). |

### Printable decomposition (generated by `make_star.py`)

The frame is split into just **two printed part types** plus pins/glue. Because
every vertex belongs to exactly one pentagon, and the 120 edges split into 60
pentagon-boundary edges (internal) + 60 inter-pentagon edges (the only links
between pentagons), the partition is clean and complete:

| file | what |
|---|---|
| `star.scad` | **STAR TILE** ×12 (all congruent): hub socket + 5 spokes + 5 corner sockets + 5 boundary bars + 10 connector mortises, fused as one pentagonal wheel (~78 mm across at D=200). |
| `connector.scad` | **CONNECTOR** ×60 (all identical — the solid is Archimedean so every edge is the same length): a flat fin with a keyed rectangular tenon at each end. |
| `stars_assembly.scad` | full-frame fit check: 12 coloured tiles + 60 connectors = the complete frame. |
| `mate_test.scad` | two neighbouring tiles + their shared connector, to check the keyed joint seats. |

**Joinery — keyed peg + socket.** The corner node wall is only ~2.2 mm before
the mushroom bore, so the mortise can't cut into the node. Instead each corner
grows a small rectangular **boss into the gap**; the connector's rectangular
tenon (which can't spin) plugs in from the gap side. Press-fit, with CA for
permanence. Joint params (`KEY_T/KEY_H/KEY_DEPTH/BACK/KEY_CLR`) live at the top
of the generated `.scad` files.

## Usage

```bash
uv run python src/mockup.py      # regenerate the PNG mockups in images/
uv run python src/make_scad.py   # regenerate models/lamp_frame.scad (monolithic)
uv run python src/make_star.py   # regenerate the printable star + connector parts
```

Open any `.scad` in `models/` and press **F5** (preview) / **F6** (render).
For quick iteration use the `mushroom_simple` family; use `mushroom.scad` only
when you need the final curved cap (it takes much longer to evaluate).
