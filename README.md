# Ssymmank lamp

Geometry and 3D-printable parts for the Günter Ssymmank Philharmonie lamp.

The lamp is a **spherical tessellation of regular pentagons, squares and
triangles** — i.e. the **rhombicosidodecahedron** (an Archimedean solid):

| | count |
|---|---|
| pentagons | 12 |
| squares | 30 |
| triangles | 20 |
| vertices | 60 |
| edges | 120 |
| faces | 62 |

Vertex configuration is `3.4.5.4` (triangle, square, pentagon, square meet at
every vertex).

Source / reference exhibition:
https://blog.sbb.berlin/darunter-sieht-man-gut-aus-ausstellung-zu-den-leuchten-guenter-ssymmanks-eroeffnet/

## Layout

Everything is organised **by component**. Each component has its generator code
under `src/<component>/` and its OpenSCAD models under `models/<component>/`.

```
src/
  core/        shared library — the solid's geometry + transform math (imported, not run)
  frame/       build_star.py (printable star/connector decomposition)
  assembly/    build_assembly.py (frame + all 72 mushrooms)
  mockups/     build_mockups.py (the images/ PNG mockups)
models/
  frame/       star · connector · stars_assembly · mate_test · test_edges · stem_fit
    renders/   transient previews / STL exports for the frame (git-ignored)
  mushrooms/   mushroom (+ simple, small/medium/large/xl, small_curved) — hand-written
    renders/   transient previews / STL exports for the mushrooms (git-ignored)
  assembly/    assembly.scad
    renders/   transient previews / STL exports for the assembly (git-ignored)
images/        reference renders (committed)
```

Generators bake all orientation maths (4×4 `multmatrix` transforms) into the
`.scad`, so each `.scad` is just data + tiny modules. The `assembly.scad`
pulls the frame from `../frame/` and the mushroom core from `../mushrooms/`.

### `src/core/` — shared library
| file | what |
|---|---|
| `geometry.py` | single source of truth — vertices, edges, faces of the solid |
| `transforms.py` | the transform helpers (`bar_transforms`, `node_transforms`, …) shared by every generator |

### `src/frame/` → `models/frame/`
| file | what |
|---|---|
| `build_star.py` → `star.scad` + … | the **printable decomposition** (below). `star.scad` is the shared library every other frame model `include`s. |

#### Printable decomposition (generated by `build_star.py`)

The frame is split into just **two printed part types** plus pins/glue. Because
every vertex belongs to exactly one pentagon, and the 120 edges split into 60
pentagon-boundary edges (internal) + 60 inter-pentagon edges (the only links
between pentagons), the partition is clean and complete:

| file | what |
|---|---|
| `star.scad` | **STAR TILE** ×12 (all congruent): hub socket + 5 spokes + 5 corner sockets + 5 boundary bars + 10 connector mortises, fused as one pentagonal wheel (~96 mm across at D=200). |
| `connector.scad` | **CONNECTOR** ×60 (all identical — the solid is Archimedean so every edge is the same length): a flat, shallow-**V** fin (kinked at its middle) with a keyed rectangular tenon at each end. |
| `stars_assembly.scad` | full-frame fit check: 12 coloured tiles + 60 connectors = the complete frame. |
| `mate_test.scad` | two neighbouring tiles + their shared connector, to check the keyed joint seats. |
| `test_edges.scad` | two connectors laid flat, for a quick fit test print. |
| `stem_fit.scad` | a real mushroom stem cone cross-cut in the hub + a corner bore, to verify clearance. |

### `models/mushrooms/` — hand-written mushroom elements
| file | what |
|---|---|
| `mushroom.scad` | detailed mushroom element — curved (spherical) pentagon cap, smooth funnel→cap blend, clipped back ribs. Accurate but heavy to render. |
| `mushroom_simple.scad` | **simplified, fast-loading** mushroom — stretched pentagon cap + cheap fins. Previews in ~0.5 s. Parametric on `STEM_LEN`. Cap curvature `CURVE_RELAX=2.3` makes the cap ~concentric with the lamp centre (radially thin, so shells shingle without intersecting); `DISH_DEPTH=26` funnel. |
| `mushroom_small.scad` · `mushroom_medium.scad` · `mushroom_large.scad` · `mushroom_xl.scad` · `mushroom_xxl.scad` | the simplified mushroom at the **five shell stem lengths** (70 / 84 / 98 / 112 / 126 mm). Each just `include`s the core and overrides `STEM_LEN`; the stem base is identical across all of them. |

### `src/assembly/` → `models/assembly/`
| file | what |
|---|---|
| `assembly.scad` | the full lamp: the frame with all 72 mushrooms, **shingled**. Achieves **zero mushroom–mushroom intersection AND zero light leak** (no straight line-of-sight from the centre escapes between caps) — both verified on the real solids by `_overlap_check.scad`. The 72 sockets are split into **5 radial shells** (stem lengths 70/84/98/112/126) by a 5-colouring of the cap-overlap graph, so every touching pair of caps sits at different radii and overlaps angularly while clearing radially; 5 mushrooms are spun about their radial axis so their stretched arms reach into the square/triangle gaps. `MUSH_SCALE=0.85`, `LAMP_SCALE=3` → 600 mm lamp. Stem tips all seat at the same bore floor, so the frame is unchanged. |
| `_overlap_check.scad` | renders only the 3-D `intersection()` of every close mushroom pair — anything visible (red) is a real physical overlap; an empty render confirms the assembly is collision-free. Regenerate after editing `assembly.scad`. |

All walls/fins are **1 mm thick** (`THICK` in `build_star.py`) — fin thickness,
socket wall, tenon thickness, boss walls. Tuned for **Ultimaker PLA** on a
0.4 mm nozzle: stem slip-fit `FIT_CLR=0.35 mm` radial, tenon press-fit
`KEY_CLR=0.30 mm` (0.15 mm/side).

**Kinked edges.** Every edge bends at its middle so each half leaves its vertex
**perpendicular to the socket axis** (tangent to the sphere) rather than dipping
in along the chord. The kink point `M` is where the sphere's tangent lines at the
two vertices meet — a few mm proud of the chord (≈5 mm for a 45 mm edge) — so the
exits are exactly perpendicular (verified to 0.0000°). `build_star.py` splits each
fused bar into two fins (`a→M`, `M→b`); the separate connectors become shallow
**V**s, and the corner mortise bosses tilt up by the tangent angle (`PHI`) so the
keyed tenons still seat. All geometry (`RAD/HALF/KINK_H/ARM_LEN/PHI`) is derived in
the `.scad` from `EDGE_LEN` and `DIAMETER`.

Print the star **hub-up** (sockets up) with a **brim** for the 1 mm walls.
Footprint ≈ 96 × 100 mm, height ≈ 21 mm — fits any Ultimaker bed.

**Joinery — keyed peg + socket.** With a 1 mm socket wall the mortise can't cut
into the node, so each corner grows a small rectangular **boss into the gap**;
the connector's rectangular tenon (which can't spin) plugs in from the gap side.
Press-fit, with CA for permanence. Joint params
(`KEY_T/KEY_H/KEY_DEPTH/BACK/KEY_CLR`) live at the top of the generated files.

**Socket clearance.** Bars run the full edge length and drive through the node
centre, so each tile's sockets are subtracted from the whole tile **last** (after
the bars union on), plus a straight clearance column out past the fin height —
otherwise the bars refill the bore or lean over the opening. `stem_fit.scad`
cross-sections a real stem cone in the hub/corner bores to verify this.

## Usage

```bash
uv run python src/mockups/build_mockups.py       # regenerate the PNG mockups in images/
uv run python src/frame/build_star.py            # regenerate the printable star + connector parts
uv run python src/assembly/build_assembly.py     # regenerate models/assembly/assembly.scad
```

Open any `.scad` in `models/` and press **F5** (preview) / **F6** (render).
For quick iteration use the `mushroom_simple` family; use `mushroom.scad` only
when you need the final curved cap (it takes much longer to evaluate).
